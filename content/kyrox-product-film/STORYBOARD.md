# KYROX Product Launch Film — storyboard

**Format:** portrait 9:16 · 1080 × 1920 · 30 fps · 38 seconds  
**Art direction:** midnight navy, narrow blue-to-violet accents, restrained grid and orbital marks, oversized editorial type, miniature product details with generous black space. A short original ambient score is generated locally from synthesized tones.

| Time | Scene | Story and motion |
|---|---|---|
| 00:00–00:06.0 | The problem | The supplied KYROX mark resolves from an orbiting line; the title “Intelligence needs a safer way to act” arrives in two clipped, staggered lines. The promise is framed as a tool boundary, not autonomous trading. |
| 00:05.6–00:12.2 | The connection | A vertical MCP flow builds from AI client to the Python FastMCP server, then branches to verified local stock fixtures and a Base Sepolia wallet reader labelled “verification in progress.” A travelling signal traces each hop. |
| 00:11.8–00:20.6 | The catalog | An animated tool call, `get_stock_info("tAAPL")`, resolves into the actual `Test Apple` fixture. The reference value is visibly labelled `MOCK`; the local record includes an empty `token_address`. Three fixture rows reveal in sequence. |
| 00:20.2–00:27.2 | The wallet reader | A public wallet address flows toward an ERC-20 `balanceOf()` read on Base Sepolia (`chainId 84532`). The result is deliberately held at “Contract verification pending” because no deployed token addresses are configured. |
| 00:26.8–00:33.7 | The boundary | Inside the KYROX server, “Private key — never enters” and “No signing / no broadcasting” remain separate from an external wallet. A single signal passes only as human-controlled data. Planned transaction preparation and simulation are called out as not implemented. |
| 00:33.3–00:38.0 | Closing | The mark and wordmark return with “Read clearly. Keep control.” The development status stays visible as the score resolves. |

The cuts overlap for 12 frames and each scene animates independently. All motion is frame-driven and deterministic; no screen capture is used as a scene.
